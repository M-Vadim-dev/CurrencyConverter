# Currency Converter App

## Описание проекта
Приложение разработано в рамках тестового задания.
Основная цель – реализация функционала конвертации валют с поддержкой обмена и истории транзакций.

## Функциональность
### Экран “Валюты”
- Отображение списка валют с флагами, названиями и балансом
- Автообновление курсов раз в секунду (через RemoteRatesServiceImpl)
- Выбор основной валюты для пересчёта
- Режим ввода суммы: пересчёт доступных валют по введённой сумме
### Экран “Обмен”
- Отображение суммы покупки, суммы оплаты и курса обмена
- Кнопка “Купить” для выполнения транзакции
- Сохранение транзакции в RoomDB и обновление балансов
### Экран “Транзакции”
- Список всех совершённых транзакций с указанием валют, суммы и времени операции
#### Дополнительно
- Баланс в рублях (75 000₽) доступен пользователю сразу при установке
- Поддержка навигации между экранами
- Интеграция с RoomDB для хранения аккаунтов и транзакций
  
## Архитектура и подход
- MVVM + Clean Architecture
- Jetpack Compose для UI
- Dependency Injection через Hilt
- Асинхронность: Kotlin Coroutines + StateFlow
- Работа с базой: RoomDB
- Navigation Component для перехода между экранами
